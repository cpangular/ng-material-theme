Container Utilities

Helper mixins for applying palette colors to container elements with automatic contrast colors.

Basic

apply-container(primary)

Simple palette application with automatic contrast colors.

Variant

apply-container(secondary, lighter-1)

Uses a lighter variant of the secondary palette.

Reverse Mode

apply-container(tertiary, $reverse-mode: true)

Swaps light/dark values - shows dark in light mode.

Disabled

apply-container(error, $disabled: true)

Reduced saturation for disabled states.

Border

apply-container(primary, $border: 2px)

Adds solid border with container color.

Elevation

apply-container(secondary, $elevation: 2)

Applies Material Design elevation shadow.

Combined

apply-container(tertiary, darker-1, $border: 1px, $elevation: 1)

Variant + border + elevation together.

Container Styles

Three style modes control how colors are applied to containers.

Filled (default)

$style: filled

Background uses palette color, text uses contrast color. Standard for cards and containers.

Text

$style: text

Transparent background, text uses palette color. For text buttons and links.

Normal

$style: normal

Inherited background, text uses palette color. For labels and inline elements.

Usage: Include @include theme.apply-container(palette, variant, options...) in your component styles. The mixin sets CSS variables and applies background, color, and border-color properties. Optionally add border thickness and elevation level.

Features

  • ✨ CSS light-dark() Support - Single theme definition for both modes
  • 🎨 Color Variants - Automatic lighter/darker/tint generation using color-mix()
  • 🔄 Instant Mode Switching - Just change color-scheme property
  • ⚡ Modern CSS - OKLab color space, CSS @property for animations
  • 🎯 Material M3 Compatible - Maps to Angular Material design tokens
  • 🛠️ Flexible Configuration - Theme-level and per-palette overrides

Element-Level Sub-Theming

Themes can be applied to any element using the theme="name" attribute, overriding the parent theme for that element and its children. This allows for rich visual hierarchy and section-based theming.

Architecture

This theming system provides a custom design token layer that generates practical color variants at build time using SCSS and CSS color-mix(). All colors support light/dark mode through CSS light-dark() function, controlled by the color-scheme property.


Configuration Hierarchy:
palette-override → theme-default → built-in-default
