Your colours

A theme is two input colours: a light primary and a dark primary. Five more palettes follow from them.

The input variables

Every palette has two inputs, --theme--light--color--palette and --theme--dark--color--palette, one per mode from chapter 2. Set them in a plain :root rule, anywhere in your CSS. The rule can come before or after the core.css link: core.css uses zero-specificity selectors, so your rule wins regardless of stylesheet order.

To use one colour in both modes, put the same value in both inputs. There is no third form.

The six palettes

Palette Comes from
primary Your inputs. The default is a quiet grey-blue.
secondary Derived from primary: hue turned 120°, more saturated.
tertiary Derived from primary: hue turned −120°.
neutral Derived from primary: almost grey, with a trace of its hue. Chapter 5 builds the surfaces from it.
neutral-variant Derived from primary: a slightly more tinted grey, used for outlines.
error Independent. A red by default; set its inputs to change it.

Each palette gives you --color--palette and --color--palette--contrast, exactly like primary in chapter 1.

Overriding a derived palette

Derivation is a default, not a rule. Set the two inputs of any derived palette and that value is used instead; the example sets tertiary to an orange that the primary's hue would never produce. Everything you do not set keeps following primary, so changing primary later still moves secondary, neutral and neutral-variant with it.
