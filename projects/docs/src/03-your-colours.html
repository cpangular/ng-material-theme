Your colours

Your colours start from two inputs: a light primary and a dark primary. Four more palettes are derived from them, and a sixth, error, has its own default. A palette is a named colour, such as primary, with its own inputs and its own tokens.

Switch between Light and Dark at the top of the page to see each mode's input: #0b5fa5 in light mode, #8ec5ff in dark.

The input variables

Every palette has two inputs, --theme--light--color--palette and --theme--dark--color--palette, one per mode from chapter 2. You write inputs; core.css turns them into the tokens you read, such as --color--primary. Do not set the tokens yourself.

Set the inputs in a :root rule, anywhere in your CSS. The rule can come before or after the core.css link: core.css writes its defaults so that any rule of yours overrides them.

To use one colour in both modes, put the same value in both inputs; there is no single input for both modes.

The six palettes

Palette Comes from
primary Your inputs. The default is a quiet grey-blue.
secondary Derived from primary: hue turned a third of the way round the colour wheel (120°), more saturated.
tertiary Derived from primary: hue turned the other way (−120°).
neutral Derived from primary: almost grey, with a trace of its hue. Chapter 5 builds the page and card backgrounds from it.
neutral-variant Derived from primary: a slightly more tinted grey, meant for borders and dividers.
error Independent. A red by default; set --theme--light--color--error and --theme--dark--color--error to change it.

Overriding a derived palette

Derivation is a default, not a rule. Set the two inputs of any derived palette and that value is used instead; the example sets tertiary to an orange that the primary's hue would never produce. Everything you do not set keeps following primary, so changing primary later still moves secondary, neutral and neutral-variant with it. Set both inputs: each mode reads only its own, so setting one leaves the other derived.

Text on a coloured box

Each palette gives you --color--palette and --color--palette--contrast, exactly like primary in chapter 1. --contrast is black or white, softened slightly toward the colour. For small text such as labels, use a third token, --color--palette--contrast--high: pure black or white, the strongest of the three. The labels in the example use it. Chapter 4 explains the three strengths and what each one guarantees.
