Getting started

One stylesheet, two variables, a readable box. Nothing is configured yet.

What you need to know first

The library is plain CSS. A token is a CSS custom property (--color--primary), and you read it with var(). If you have used var(--my-colour) before, you know everything this chapter needs.

Include the stylesheet

Install the package and load core.css by its package path, before your own styles: 

npm install @cpangular/ng-material-theme
<link rel="stylesheet" href="node_modules/@cpangular/ng-material-theme/css/dist/core.css">

With a bundler, import it instead: import "@cpangular/ng-material-theme/core.css". The example pages on this site load the same file from one folder up, ../core.css, because the site copies it next to the pages.

A token and its contrast

core.css defines every token with a default value, so the box above works with no configuration. --color--primary is the main colour. --color--primary--contrast is the text colour to use on it: black or white, whichever reads better, chosen by the browser from the actual colour. Every colour token comes with a --contrast partner, so you never pick a text colour by hand.

The default primary is a quiet grey-blue. The next chapters make it follow light and dark mode, then make it yours.

Browser baseline

Chrome 123, Firefox 128, Safari 17.5 (mid 2024). The library relies on light-dark(), relative colour syntax and color-mix(), and ships no fallbacks for older browsers.
