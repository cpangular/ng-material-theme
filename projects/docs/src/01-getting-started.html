Getting started

One stylesheet, two tokens, a readable box. Nothing is set yet; every value is a default.

What you need to know first

The library is plain CSS. Its values are custom properties, called tokens, that you read with var(). If you have used var(--my-colour) before, you are ready. You do not need Angular or Angular Material; chapter 15 covers using the library with Material.

Include the stylesheet

Install the package and load core.css by its package path:

npm install @cpangular/ng-material-theme
<link rel="stylesheet" href="node_modules/@cpangular/ng-material-theme/css/dist/core.css">

With a bundler, import it instead: import "@cpangular/ng-material-theme/core.css". The package maps that short path to css/dist/core.css, so both load the same file.

A token

core.css gives its tokens default values, so the box above works with nothing set. --color--primary is the main colour; the box uses it as its background. The default is a quiet grey-blue.

Its contrast

--color--primary--contrast is the text colour to use on primary: black or white, whichever reads better on it. core.css works it out from --color--primary itself, so it stays right when primary changes, and you never pick a text colour by hand.

Token names are parts joined by --: the group (color), the role (primary), then anything extra (contrast). Every colour token has a partner named by adding --contrast: --color--X pairs with --color--X--contrast.

Chapter 2 makes the colour follow light and dark mode; chapter 3 makes it yours.

Source

The example loads ../core.css, a copy the site keeps next to the examples. Every example on this site does the same; in your project, use the package path above.

Browser baseline

Supported browsers: Chrome 123, Firefox 128 and Safari 17.5 (mid 2024). core.css uses light-dark(), relative colour syntax and color-mix() internally and has no fallbacks for older browsers. You never have to write these functions yourself; they are listed only so you know which browsers are supported.
