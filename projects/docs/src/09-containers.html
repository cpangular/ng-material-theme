Containers

Two Sass mixins turn a palette, a variant and a style into a readable box: apply-container() paints it, and apply-container-vars() only hands you the colours. Every token they use comes from chapters 4 and 5. Both are Sass-only; with core.css, set background and color to the same tokens by hand.

apply-container()

@include theme.apply-container($palette, $variant: null, $reverse-mode: false, $disabled: false, $style: filled, $border: null, $elevation: null);

Arguments with a default are optional; pass them by name, as in $style: text. The palette and variant form a chapter 4 token name: apply-container(primary, higher-1) sets background to --color--primary-higher-1 and color to --color--primary-higher-1--contrast. The Filled button uses it on :hover, because higher-1 stands out more in both modes.

Which text colour

A filled container's text is the plain --contrast, which chapter 4 guarantees only at 3:1. The example's labels happen to read at 4.5:1 or better, but with your colours they may not. For a guaranteed 4.5:1, follow the include with color: var(--color--primary--contrast--high); (or the matching token for your palette and variant).

Borders, elevation, reverse mode, disabled

$border is a width: the mixin draws a solid border of that width in the border colour from the table below. $elevation: N sets box-shadow to chapter 5's --elevation-N, as on the Delete button. $reverse-mode: true and $disabled: true add -reverse-mode and -disabled to the token name. The Disabled button is faded like any -disabled token and reads below 4.5:1 on purpose.

The three styles

$style Background Text Border
filled the colour its --contrast the colour
text transparent the colour the colour
normal none of its own (the parent shows through) the colour the colour

Filled is a solid button or chip; its border matches the fill, so a border only adds size. Text has a transparent background and palette-coloured text; add $border for an outlined button. Normal paints no background of its own and uses the palette colour for text and border.

apply-container-vars()

It takes the same arguments except $border and $elevation. It sets five variables and no properties, so the element and its children decide what to paint:

  • --container-bg-color and --container-color: the pair the style describes.
  • --container-border-color: the colour.
  • --container-color--high and --container-color--low, below.
$style --container-color--high --container-color--low
filled its --contrast--high (4.5:1) its --contrast--low (decorative)
text, normal its -higher-1 its -lower-1

On a coloured box the text needs a contrast colour; with no box it needs a palette colour, and those carry no contrast guarantee against the page. For text and normal, use the two without $variant or $reverse-mode: with either set, the names they build do not exist.

The cards use it. The filled card's heading and body text use --container-color--high, and its divider uses --container-color--low, which chapter 4 keeps for decoration. The normal card sets its own background, because the variables paint nothing, and its body text uses --container-color, the palette colour.
