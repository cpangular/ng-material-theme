ng-material-theme

A framework-free theming library where the browser is the theme engine. A theme is a handful of input colours; everything else is derived in CSS with light-dark(), oklch(from …) and color-mix().

Each chapter below teaches one thing, with a live example first. A chapter uses only what the chapters before it introduced, and every example is a real page that loads the real library. The chapters are written to be read in order.

The Reference lists every token, drawn live in the current theme.

Install

npm install @cpangular/ng-material-theme

Then follow Getting started.

Browser baseline

Chrome 123, Firefox 128, Safari 17.5 (mid 2024). The library needs light-dark(), relative colour syntax and color-mix(); there are no fallbacks for older browsers.
