Using Sass

The same library as a Sass module: core() emits what core.css contains, and createTheme() writes the theme rules for you. This chapter assumes you know Sass modules (@use, @include) and maps. Chapters 8 and 9 need Sass; the others work with plain CSS.

This is chapter 6 rebuilt in Sass. Below is chapter 6's CSS version again for comparison. They match except for mint: here it is one colour used in both modes (the first shape in Config shapes), so mint's panel and the dark card inside it differ from chapter 6.

Loading the module

Add node_modules to Sass's load path and use the package by name: 

@use "@cpangular/ng-material-theme/theming" as theme;

On the command line that is sass --load-path=node_modules styles.scss styles.css; link the CSS it produces. as theme is only the Sass namespace, and any name works. If your build enables Sass's Node package importer (sass --pkg-importer=node; most bundler Sass loaders do), you can write pkg:@cpangular/ng-material-theme/theming instead, as the examples on this site do.

core() replaces the link

core() and createTheme() are mixins: you call them with @include. @include theme.core(); emits exactly what core.css contains. Use one or the other, never both: a page that links core.css and also compiles core() ships the whole library twice. The example page therefore has no core.css link, only its own compiled stylesheet.

createTheme()

@include theme.createTheme("ember", (colors: (primary: (#c2410c, #fb923c))));

createTheme($name, $config) is the Sass form of chapter 6's [theme="name"] { inputs } rule. The config is a map with a colors key, one entry per palette. It writes only the inputs the config names, so a nested theme inherits and re-derives exactly as in chapter 6. Any of the six palettes may appear, and one left out is inherited or re-derived as in chapter 6.

The default theme

@include theme.createTheme("sea", (colors: (primary: (#0b5fa5, #8ec5ff))), $is-default: true);

$is-default: true is chapter 3's :root rule: the theme applies to the page when <html> has no theme attribute. It keeps its name too, so theme="sea" also selects it.

Config shapes

Shape Meaning
primary: #0f9f8f One colour: sets both inputs to the same value (chapter 3).
primary: (#0b5fa5, #8ec5ff) Light first, dark second: sets --theme--light--color--primary and --theme--dark--color--primary.
