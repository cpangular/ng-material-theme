Tuning

The percentages behind the variants are variables too. Change one for a whole theme, or for one palette inside it.

Compare each panel with defaults. The --theme--blend--darker-1: 50% panel darkens -darker-1 for every palette. The --theme--opacity--5 panel strengthens tint-5. The --theme--disabled-saturation panel keeps the disabled swatch's full colour. The -override panel darkens -darker-1 for primary only, so secondary-darker-1 is untouched. soft does the last three at once, in Sass.

The solid swatches use --contrast--high. The tint-5 and -disabled labels read below 4.5:1 on purpose: they are there to show what tuning does to those swatches.

The tuning variables

Variable Default Controls
--theme--blend--darker-1, --theme--blend--darker-2 80%, 30% The share of the colour kept when mixing toward black; the rest is black. A smaller number is darker.
--theme--blend--lighter-1, --theme--blend--lighter-2 30%, 5% The share kept when mixing toward white. A smaller number is lighter.
--theme--opacity--1 … --theme--opacity--9 2, 8, 12, 16, 25, 40, 55, 70, 90% The opacity of -tint-1 to -tint-9.
--theme--contrast-blend--high, --theme--contrast-blend, --theme--contrast-blend--low 100%, 90%, 80% Each contrast colour starts as black or white and is mixed with the colour it sits on; this is how much of the black or white is kept. High protects chapter 4's 4.5:1 and the middle one its 3:1; lowering either below its default gives that guarantee up. Low has none.
--theme--disabled-saturation 40% How much colour a -disabled variant keeps.
--theme--disabled-foreground-opacity, --theme--disabled-background-opacity 70%, 80% The opacity of the text colour -disabled--contrast and of the fill -disabled.

-higher and -lower use the same blends: in light mode -higher-1 is -darker-1, in dark mode it is -lighter-1.

Like primary and error, a nested theme inherits the tuning values it does not set (chapter 6).

Per-palette overrides and the fallback chain

Each palette reads every tuning value through a chain with an override in front: 

--color--primary--blend--darker-1: var(--color--primary--blend--darker-1-override, var(--theme--blend--darker-1));

The library declares --color--primary--blend--darker-1 itself; you never set it. The -override in front of it is the slot it leaves for you. The rule is: --theme--X becomes --color--palette--X-override. Set it and that palette alone changes; leave it unset and the theme-level value applies. For example --color--error--opacity--5-override, --color--primary--contrast-blend--low-override, --color--primary--disabled-saturation-override.

Where an override must sit

Tuning values and their overrides take effect only in a :root rule or on an element with a theme attribute. As chapter 6 showed, the library works out the tokens there, and the elements inside receive finished colours. Setting --theme--blend--darker-1 on a plain <div> arrives after that work is done and changes nothing. That is why each panel in the example is a theme="sea" element with an inline style: the attribute makes the library work out the tokens again on that panel, as in chapter 6's A theme attribute with no rule. color-scheme works on any element because it only picks between two finished values; tuning changes how the values are made.

The Sass shape

In createTheme(), theme-level tuning is four optional maps beside colors. Per-palette tuning goes inside the palette: its colour moves under value and the tuning keys sit beside it, as primary: (value: (#0b5fa5, #8ec5ff), blend-darker-1: 50%).

CSS variable Theme-level map and key Per-palette key
--theme--blend--darker-1 (also darker-2, lighter-1, lighter-2) blends: (darker-1: …) blend-darker-1
--theme--opacity--5 (1 to 9) opacities: (opacity5: …) opacity5
--theme--contrast-blend--high, --theme--contrast-blend, --theme--contrast-blend--low contrast-blends: (high: …, default: …, low: …) contrast-blend-high, contrast-blend, contrast-blend-low
--theme--disabled-saturation, --theme--disabled-foreground-opacity, --theme--disabled-background-opacity disabled: (saturation: …, foreground-opacity: …, background-opacity: …) disabled-saturation, disabled-foreground-opacity, disabled-background-opacity

Sass writes a variable only for each key you give; everything else keeps its default.
