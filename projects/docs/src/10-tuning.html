Tuning

The percentages behind the variants are variables too. Change one for a whole theme, or for one palette inside it.

Compare each panel with the first. The second changes how dark -darker-1 is for every palette; the fifth changes it for primary only, so secondary-darker-1 is untouched.

The tuning variables

Variable Default Controls
--theme--blend--darker-2, --theme--blend--darker-1 30%, 80% How much of the colour survives when mixing toward black. Lower is darker.
--theme--blend--lighter-1, --theme--blend--lighter-2 30%, 5% The same toward white. Lower is lighter.
--theme--opacity--1 … --theme--opacity--9 2% … 90% The opacity of -tint-1 to -tint-9.
--theme--contrast-blend--high, --theme--contrast-blend, --theme--contrast-blend--low 100%, 90%, 80% How much of the black or white base is kept in each contrast colour. Lowering --contrast-blend below the default gives up the 3:1 guarantee of chapter 4.
--theme--disabled-saturation 40% How much colour a -disabled variant keeps.
--theme--disabled-foreground-opacity, --theme--disabled-background-opacity 70%, 80% The opacity of disabled text and of a disabled fill.

They behave like the colour inputs of chapter 3: set them in a :root rule or a theme rule, and a nested theme inherits what it does not set.

Per-palette overrides and the fallback chain

Each palette reads every tuning value through a chain with an override in front: 

--color--primary--blend--darker-1: var(--color--primary--blend--darker-1-override, var(--theme--blend--darker-1));

Set --color--palette--key-override and that palette alone changes; leave it unset and the theme-level value applies. The override names follow the variable names: --color--error--opacity--5-override, --color--primary--contrast-blend--low-override, --color--primary--disabled-saturation-override.

Where an override must sit

Tuning values and their overrides take effect only on :root or on an element with a theme attribute. The chains above are evaluated there, and everything below inherits their results, not their inputs. Setting --theme--blend--darker-1 on a plain <div> does nothing; the panels in the example are therefore theme="sea" elements with an inline style, and the attribute alone is what makes them a boundary (chapter 6).

The Sass shape

In createTheme(), theme-level tuning is four optional maps beside colors: blends, opacities, contrast-blends and disabled, with the keys shown in the soft theme above. A per-palette override is written inside the palette by giving it a value and the keys beside it: blend-darker-1, opacity5, contrast-blend-low, disabled-saturation, and so on. Only the keys you name are emitted, exactly as in CSS.
