Custom palettes

A palette beyond the six, with the whole variant family of chapter 4. This needs Sass.

Adding a palette

Name a palette in createTheme()'s colors map that is not one of the six standard ones, and it becomes a palette. brand above takes the same two shapes as any palette: a single colour, or a light and dark pair. From then on every token the grammar in chapter 4 allows exists for it: --color--brand, --color--brand-darker-1--contrast--high, --color--brand-tint-3, and so on, with the same contrast guarantees.

Why Sass only

core.css derives the six standard palettes and nothing else; it cannot know your palette names. createTheme() emits the derivation for a custom palette inside the theme's own rule, so the palette exists wherever the theme applies, including nested themes that inherit it. A plain CSS theme can set the inputs of the six standard palettes, but it cannot add a seventh.

Where it lives

A custom palette belongs to the theme that declares it. Declare it in the default theme ($is-default: true, as here) to have it everywhere, or in a named theme to have it only inside that theme. Two themes may declare the same palette name with different colours; a nested theme that does not declare it inherits the parent's tokens.
