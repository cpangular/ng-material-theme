Light and dark

Every token has a light value and a dark value. One CSS property decides which one you see, on any element.

Press Light, Dark and Auto at the top of this page. The first two panels do not move. The third follows.

The default follows the OS

core.css sets color-scheme: light dark on the root element. That is the browser's own switch for light and dark mode: with both keywords, the page follows the operating system preference, with no script.

Forcing a mode on any element

color-scheme: light or color-scheme: dark on an element forces that mode for the element and everything inside it. Nothing else is needed: no attribute, no class, no second stylesheet. The token keeps both values and resolves to the right one wherever it is used, so a dark panel inside a light page is one declaration.

The browser's own page colours follow the same switch. The panels above use Canvas and CanvasText for their background and text so that you can see it. Chapter 5 replaces them with the library's surfaces.

Two values per token

The box is --color--primary in all three panels. In the light panel it is the light primary, in the dark panel the lighter dark primary, and its --contrast flips with it. Which value a token resolves to is decided by the nearest color-scheme above the element that reads it. The next chapter sets those two values.
